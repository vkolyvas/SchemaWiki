## About This Project

SchemaWiki is an AI-native feature documentation and engineering memory system that enables coding agents to document, track, and recreate features using a replay protocol.

### Key Features

- **Auto-Analysis**: Automatically analyzes git commits to detect what the AI agent did
- **Wiki Generation**: Creates beautiful wiki pages for every significant change (>50 LOC or >5 files)
- **GitHub Pages**: Automatic deployment to GitHub Pages via CI/CD
- **Feature Tracking**: Each feature gets its own detailed page with summary, changes, and commit details
- **Navigation**: All pages link back to the main wiki for easy browsing

### How It Works

1. When code is pushed to the repository, the CI workflow runs `schema_analyzer.py`
2. The analyzer calculates LOC (lines of code) changes and detects feature types from commit messages
3. If the change is significant (>50 LOC or >5 files), a new feature page is created
4. The main README is updated with links to all features
5. GitHub Pages is automatically updated with the new content
